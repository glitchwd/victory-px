VIctory Proton eXecutor

victory-px

Linux TUI launcher, telemetry monitor, and benchmark suite for running VIctory builds through Wine, Proton, and Gamescope.

Overview Setup & Launch Fork Inventory Display & Gamescope Reporting

Documentation

Setup & Launch

Build from source, configure Wine prefixes, environment defaults, and helper scripts.
Fork Inventory

Tiered ASCII loadout, rarity tiers, CLI registration, and custom fork profiles.
Display & Gamescope

Wine direct vs Gamescope, presets, FSR upscaling, fullscreen, and FPS limits.
Reporting

Lighthouse HTML, Markdown Report, and headless benchmarks.

Quick Start

cargo build --release --locked --manifest-path victory-px-rs/Cargo.toml
./victory-px-rs/target/release/victory-px --help
./victory-px-rs/target/release/victory-px

Keybindings

KeyAction
1 / 2 / 3Open Monitor, Display, or Lighthouse
B / NOpen the loadout or add a fork from it
O / GBrowse for the title executable or configure Gamescope
CChange the console profile while stopped
SStart or stop the session
R / WSave Lighthouse HTML or Markdown Report
TAdjust the logo theme and animation
X / VOpen highlighted fork folder or game folder
Q / Ctrl+CQuit and stop the session
