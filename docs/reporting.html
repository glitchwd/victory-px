Reporting

Export Lighthouse HTML reports, Markdown Report bundles, and run repeatable headless benchmarks.

Overview Setup & Launch Fork Inventory Display & Gamescope Reporting

Exports

  • 3 opens the Lighthouse panel, including the Saved Reports list (↑/↓ to select, Enter to open, Del to delete a report and its attached screenshot).
  • R saves lighthouse-*.html (with an in-game screenshot *.png attached when available) and asks xdg-open to display it.
  • W saves report-*.md (with an in-game screenshot *.png attached when available) with a short message and a full report outline.

Reports live in ${XDG_STATE_HOME:-~/.local/state}/victory-px/reports/ with mode 0600 and unique filenames.

Headless Benchmark

./victory-px-rs/target/release/victory-px --fork my-build --exe /path/to/title.exe \
  --bench --duration 30

The command stops after the requested duration or when the child exits. It prints the results and writes both reports without requiring a terminal UI or desktop opener.

What the Reports Contain

Both formats use recognized numeric telemetry, warning and error counts, launch settings, run duration, and coarse hardware details such as GPU vendor and memory capacity. They omit raw logs, paths, custom profile names, custom runtime labels, and host probe strings.

Performance compares measured FPS to 60 FPS. Stability is a heuristic based on logged warnings and errors. Headroom uses detected VRAM and shows unavailable when that probe yields no reading.

Session Logs

Victory-PX hides path-bearing child output in the monitor, including Windows, Wine and Linux paths. In the Rust monitor, hold Ctrl+P to temporarily preview the original lines on terminals that report key releases; this preview is excluded from reports and saved logs.
